# جزر أمان 🏝️

لعبة ثلاثية الأبعاد تعلّم البنات من ٧ إلى ١٠ سنوات أربع قواعد للأمان الرقمي:

| الجزيرة | الموضوع |
|---|---|
| 🔑 جزيرة الكنز | سرية كلمة المرور |
| ⏰ جزيرة الوقت | تنظيم وقت الشاشة |
| 🎁 جزيرة الهدايا | الاستئذان قبل التحميل |
| 💬 جبل الأسرار | الغرباء عبر الإنترنت |

في النهاية: تحدي مراجعة، وشارات، وشهادة باسم البطلة.

**طريقة التشغيل:** افتحي `index.html` في أي متصفح (آيباد أو كمبيوتر). البطلة تمشي بسحب الإصبع أو لمس الأرض.

مشروع طالبات — المؤسسة العامة للتدريب التقني والمهني.
